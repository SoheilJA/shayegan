# گروه شایگان | شایگان گروپ

[![Open in GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Deployed-007ec4?style=for-the-badge&logo=github)](https://soheilja.github.io/shayegan/)

صفحهٔ رسمی و مینیمال **گروه شایگان** — قدیمی‌ترین شرکت ساختمانی و عمرانی ایران (تأسیس ۱۳۰۷ / ۱۹۲۸ میلادی).

> **دیدن کنید:** [https://soheilja.github.io/shayegan/](https://soheilja.github.io/shayegan/)

## در یک نگاه

- **طراحی، مدیریت و اجرای** پروژه‌های عمرانی، زیرساختی، مسکونی و صنعتی
- از بزرگراه نیایش تا ساختمان هوشمند **فرشته پالاس**
- همکاری با بانک صادرات ایران و بانک خاور میانه
- نزدیک به یک قرن تجربه در ساختن زیرساخت‌های کشور

## فایل‌ها

| فایل | توضیح |
|------|-------|
| `index.html` | صفحهٔ اصلی تک‌فایلی (تمام محتوا + استایل + جاوااسکریپت در یک فایل) |
| `logo.png` | لوگوی اصلی مجموعه |
| `favicon.png` | نماد مرورگر |

## ویژگی‌های طراحی

- طراحی RTL-first با فونت **Vazirmatn**
- پالت رنگی: چرک خاکی / عاجی / بُرُنز (`#BD9753`)
- سیستل حرکتی یکپارچه (reveal + stagger)
- نمای گرافیکی سه‌بعدی هویت در بخش هِرو
- معماری صفحات با هش (hash-based router) بدون نیاز به build

## اجرا محلی

```bash
# فقط کافی است فایل را در مرورگر باز کنید
start index.html
```

یا با یک سرور محلی ساده:

```bash
python3 -m http.server 8000
# سپس به آدرس http://localhost:8000 مراجعه کنید
```
